React Hooks

Como os Hooks transformaram a forma de criar componentes no React

📌 O que são Hooks?

Hooks são funções especiais introduzidas no React 16.8 que permitem usar estado, ciclo de vida e outras funcionalidades sem precisar de classes. Eles tornam o código mais simples, organizado e fácil de reutilizar.

⚡ Principais Hooks

  • useState — controla variáveis reativas
  • useEffect — executa efeitos colaterais
  • useMemo — otimiza cálculos
  • useContext — compartilha estado global
  • useRef — cria referências persistentes

📘 Exemplo Prático (React real)

import { useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Clique: {count}
    </button>
  );
}

🌟 Por que os Hooks são importantes?

Eles permitem:

  • Menos código e mais legibilidade
  • Componentes mais fáceis de testar
  • Reutilização de lógica (custom hooks)
  • Melhor organização da aplicação
