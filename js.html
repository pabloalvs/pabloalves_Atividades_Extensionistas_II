📌 O que é JavaScript?

JavaScript é a principal linguagem para desenvolvimento web. É usada para criar interatividade, animações, aplicações completas e até servidores.

🚀 Recursos Modernos

  • Arrow Functions
  • Destructuring
  • Async/Await
  • Classes
  • Módulos ES

📘 Exemplo Prático (ES6)

const user = { name: "Pablo", age: 20 };
const { name } = user;

console.log(`Olá, ${name}!`);

Declaração com let, const e exemplos de tipos primitivos.

🔧 Funções (tradicionais e arrow)

Funções nomeadas, anônimas e arrow functions.

// função tradicional
function soma(a, b) {
    return a + b;
}

// arrow function
const dobro = x => x * 2;

console.log(soma(2,3)); // 5
console.log(dobro(4));  // 8

📚 Arrays e métodos úteis

Map, filter, reduce e iteração.

const nums = [1,2,3,4,5];

const pares = nums.filter(n => n % 2 === 0);
const dobrados = nums.map(n => n * 2);
const somaTotal = nums.reduce((acc, n) => acc + n, 0);

console.log(pares); // [2,4]
console.log(dobrados); // [2,4,6,8,10]
console.log(somaTotal); // 15

⏳ Promises e fetch

Exemplo simples de usar fetch com Promises (API pública).

// Exemplo de fetch (requisição GET)
fetch('https://jsonplaceholder.typicode.com/todos/1')
    .then(response => response.json())
    .then(data => console.log('fetch ->', data))
    .catch(err => console.error('Erro:', err));

async / await

Forma moderna e mais legível de trabalhar com Promises.

async function pegarTodo() {
    try {
        const res = await fetch('https://jsonplaceholder.typicode.com/todos/1');
        const todo = await res.json();
        console.log('async/await ->', todo);
    } catch (err) {
        console.error('Erro async:', err);
    }
}

pegarTodo();

🖱 Manipulação do DOM e Eventos

Adicionar um botão dinamicamente e escutar clique.

// cria botão e adiciona ao body
const btn = document.createElement('button');
btn.textContent = 'Clique aqui';
btn.style.padding = '8px 12px';
document.body.appendChild(btn);

btn.addEventListener('click', () => {
    alert('Você clicou!');
});
