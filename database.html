Banco de Dados SQL

Conceitos fundamentais de tabelas, consultas e relações

📌 O que é SQL?

SQL (Structured Query Language) é a linguagem usada para criar, consultar e manipular dados em bancos de dados relacionais como MySQL, PostgreSQL, Oracle e SQL Server.

📊 Estrutura de um Banco de Dados

  • Tabelas — conjuntos de registros (linhas)
  • Colunas — os campos de cada registro
  • Chave Primária (PK) — identifica cada linha
  • Chave Estrangeira (FK) — cria relações entre tabelas

📘 Exemplo de Consulta SQL

SELECT name, email
FROM users
WHERE active = 1;

🔍 Para que o SQL é usado?

  • Gerenciar grandes volumes de dados
  • Criar relatórios
  • Fazer buscas rápidas e precisas
  • Controlar permissões e segurança
  • Integrar sistemas e aplicativos
