CSS Grid & Flexbox

Aprenda como criar layouts modernos, flexíveis e responsivos

📌 Grid vs Flexbox

Grid é um sistema de layout bidimensional — controla linhas e colunas.
Flexbox é um sistema unidimensional — controla apenas linhas ou colunas.

Usados juntos, permitem criar layouts modernos com pouco código.

📐 Exemplo: CSS Grid

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

📦 Exemplo: Flexbox

.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

🔍 Quando usar cada um?

  • Grid: dashboards, galerias, layouts de página
  • Flexbox: barras de navegação, cards, componentes alinhados
  • Ambos podem ser combinados em layouts complexos
