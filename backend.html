📌 O que é REST?

REST (Representational State Transfer) é um conjunto de princípios para comunicação entre cliente e servidor usando HTTP. Ele define como recursos devem ser acessados, representados e manipulados.

🔗 Exemplo de endpoints REST

GET /api/users
POST /api/users
DELETE /api/users/:id

🧩 Características de uma API RESTful

  • Baseada em recursos (URLs representam objetos)
  • Opera sobre HTTP (GET, POST, PUT, DELETE...)
  • Sem estado (stateless)
  • Retorna dados em JSON ou XML
  • Padronização e previsibilidade
